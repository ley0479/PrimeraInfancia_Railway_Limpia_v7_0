# Privacidad de LÍA

LÍA minimiza el contexto y no necesita nombres de menores, documentos, NUI,
teléfonos, direcciones ni diagnósticos individuales para orientar. El servicio
de redacción oculta identificadores extensos, correos y secretos. La auditoría
guarda evento, módulo, herramienta, resultado, latencia futura y `request_id`,
pero no el texto original de la pregunta ni el audio.

El micrófono se activa únicamente por interacción. La primera versión usa la
transcripción del navegador y no almacena grabaciones. Preferencias, feedback,
progreso y auditoría incluyen fundación y usuario.
