# Base de conocimiento de LÍA

`guides.py` contiene conocimiento institucional curado por módulo: propósito,
insumos, pasos, resultado y errores frecuentes. Solo se entrega una guía si el
rol puede abrir el módulo según `ROLE_MENU_PERMISSIONS`.

Para agregar contenido: actualizar la entrada del módulo, conservar lenguaje
verificable, añadir al menos tres pasos y ejecutar
`test_lia_flags_guides_v7.py`. No incluir nombres de menores, políticas no
confirmadas, credenciales ni instrucciones encontradas dentro de documentos.
