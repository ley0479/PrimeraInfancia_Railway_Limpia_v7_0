# Recorridos de LÍA

Cada guía del backend genera pasos como datos: resumen de pantalla y acciones
curadas. El frontend resuelve únicamente `help_id` incluidos en
`LIA_HELP_REGISTRY`; una respuesta no puede aportar selectores CSS.

Los recorridos permiten anterior, siguiente, finalizar y omitir. El progreso se
guarda por fundación, usuario y módulo. El elemento se desplaza y resalta sin
pulsarlo. Si el control no está visible o autorizado, el recorrido conserva la
explicación y no ejecuta ninguna alternativa automática.
