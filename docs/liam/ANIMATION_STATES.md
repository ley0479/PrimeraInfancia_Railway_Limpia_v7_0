# Estados de animación

El registro cerrado contiene: `hidden`, `loading`, `idle`, `greeting`, `listening`, `thinking`, `speaking`, `guiding`, caminata, giros, señalamiento, lectura de tablet, teletransporte, éxito, advertencia, error, desconexión, silencio y reposo. Con el póster solo se simulan estados básicos mediante CSS; los estados corporales completos requieren Rive/Lottie/Live2D.
